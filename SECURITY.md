# Security Policy

## Supported versions

Only the latest release receives security updates. Older releases are not
supported.

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report them privately through GitHub's private security advisory on this
repository: **Security → Report a vulnerability**.

Include as much of the following as you can:

- affected version(s) and platform (macOS, Windows, Linux),
- a short description of the issue,
- steps to reproduce,
- the potential impact.

We aim to acknowledge reports promptly and publish a fix together with an
advisory.

## Scope

In scope: the application itself, its bundled dependencies as shipped, and the
build pipeline.

Out of scope (report to the provider instead): third-party services used at
runtime — Quran.com, MP3Quran, QDC, Pexels, Unsplash, Pixabay, Pollinations,
and the public Hugging Face aligner.

## Preferences

- Write in English or Indonesian.
- Prefer proof-of-concept steps over raw exploits where possible.
